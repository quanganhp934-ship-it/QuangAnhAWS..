# Event Summary: “FCAJ Community”

### Event Overview
*   **Event Title**: FCAJ – Learn • Build • Share • Grow
*   **Date**: 09:00 – 12:00 | Saturday, 15/08/2026
*   **Location**: Grand Terra Tower (AWS Vietnam Office)
*   **Organizer**: AWS G3 Team in collaboration with First Cloud Journey Community
*   **Role**: Participant

---

### Objectives & Goals
*   Learn how to use LinkedIn and build a personal brand to create new opportunities for your studies and professional career.
*   Explore the cloud and build a foundation for the journey ahead.
*   Explore common hosting and server models, understand the differences between each option, and—most importantly—determine which solution is the right fit for a given set of requirements.

---

### Speakers
*   **Phung Hai Long**: Marketing Manager, Thành Công Group

*   **Phuong Nguyen**

*   **Pham Minh Quang**
---

### Key Highlights

#### 1. Personal Branding with LinkedIn
*   **Topic**: LinkedIn & How to build Personal Branding
*   **Speaker**: Phung Hai Long.
*   **Content**: Beyond technical knowledge, how we shape our image and showcase our personal value is also crucial. Let’s explore how to leverage LinkedIn and build a personal brand to unlock new opportunities in your education and career.

#### 2. The Cloud World
*   **Topic**: The Very First Step into the Cloud.
*   **Speaker**: Phuong Nguyen.
*   **Content**: Where should one begin with the Cloud? This session will provide foundational knowledge and initial perspectives for those looking to step into the world of Cloud computing and build a base for their journey ahead.

#### 3. Suitable infrastructure
*   **Topic**: Right Server, Right Job – Comparing Hosting Types and Server Options
*   **Speaker**: Pham Minh Quang.
*   **Content**: Let's learn about popular hosting and server models, the differences between each option and most importantly: what is the right solution for each problem?

---

### Key Learnings

#### 1. Technical Mindset & Methodology
*   **Cloud Mindset**: Cloud is not just renting compute; it's designing automated, horizontally scalable systems backed by pay-as-you-go financial models.
*   **Data Security**: Raw data preparation determines ML accuracy and detection performance.

#### 2. Practical Expertise
*   Understood how to handle imbalanced datasets when training ML classifiers.
*   Learned basic Docker CLI syntax and real-time WebSockets integration on serverless AWS architectures.

#### 3. Best Practices in Operations
*   **Golden Rule**: Never patch or test system configurations directly on the Production environment.
*   Always automate repetitive operational tasks and maintain clear technical documentation.

*   **Workflow Improvement**: Implement real-time network threat monitoring dashboards.
